# 데블스 플랜 & 더 지니어스 · 교실 두뇌 게임

데블스 플랜·더 지니어스의 게임을 차용해 **초등 6학년 교육과정(수학)과 연계**한 웹앱입니다.
GitHub(코드) → Netlify(화면 + 서버 함수) → Neon(데이터베이스) 로 구성됩니다. 빌드 과정이 없어 그대로 배포됩니다.

현재 게임: **기억 포커** · **결합** · **십이장기** (모두 2인 / 컴퓨터 연습)

### 십이장기 (6학년 수학)
가로 3칸 × 세로 4칸 판에서 하는 장기. 시작 배치는 영상 화면과 같고(아래쪽: 상·왕·장 + 왕 앞의 자), 두 번째 사람에게는 판을 180° 돌려 항상 내 말이 아래쪽에 보입니다.
- 말: 왕(8방향) · 장(상하좌우) · 상(대각선 4방향) · 자(앞으로 1칸, 상대 진영 맨 끝줄에 들어가면 후로 승급) · 후(대각선 뒤쪽을 뺀 6방향)
- 잡은 말은 내 말이 되어 빈 칸에 내려놓을 수 있습니다(상대 진영 줄에는 불가, 후를 잡으면 자로 돌아감 — 영상에 없어 일반 규칙을 따랐습니다).
- 이기는 조건: ① 상대 왕 잡기 ② 내 왕이 상대 진영(맨 끝줄)에 들어간 뒤 상대가 다음 수에서 잡지 못하면 승리. 같은 판이 3번 나오면 무승부, 200수가 넘어도 무승부.
- **힌트(학습 연계)**: 말을 놓고 5초 안에 `힌트로 무르기` → 수학 문제 → 맞히면 방금 둔 수를 물리고 같은 턴에 다시 둡니다(잡은 말도 돌려놓음). 틀리거나 시간이 지나면 힌트는 사라지고 수는 그대로 확정됩니다. 힌트는 **내 턴 5번마다 1개 충전, 최대 3개, 한 턴에 한 번**. 힌트가 없으면 5초 확인 시간 없이 바로 다음 사람으로 넘어갑니다.
- 문제: 분수의 나눗셈 · 소수의 나눗셈 · 비례배분(기억 포커와 같은 생성기) + 구구단(2~9단). 시작할 때 종류를 고를 수 있습니다.
- 컴퓨터: 몇 수 앞을 내다보는 깊이(쉬움 1수 / 보통 3수 / 어려움 4수)와 아무 수나 두는 실수 확률(35% / 12% / 3%)로 난이도를 나눕니다. 1.5~5초 안에 둡니다. `lib/games/twelve-janggi/ai.js` 의 `LEVELS`.
- 숫자(한 수 60초, 확인 5초, 문제 45초, 시작 힌트 1개 등)는 `twelve-janggi/index.js` 맨 위 상수에서 바꿉니다. 한 수를 60초 안에 못 두면 자동으로 아무 수나 둡니다.

### 결합 (5·6학년 사회)
더 지니어스 2 데스매치 '결! 합!'을 차용. 카드 27장(모양·색·배경색 각 3종) 중 9장이 공개되고, 세 속성이 각각 "모두 같거나 모두 다른" 카드 3장이 **합**입니다.
- 라운드는 시작할 때 **3 · 5 · 10** 중 선택, 번갈아 한 턴 **30초**(원래 10초). 합 정답 +1 / 오답 -1, 합이 더 없을 때 **결** +3 / 틀리면 -1. 합을 부른 뒤 3장 지목은 5초.
- 아무도 합·결을 부르지 않은 채 6턴이 지나면 라운드 종료. 이미 나온 합은 다시 불러도 점수 없이 안내만 나옵니다.
- 힌트(사회 단답식 문제를 맞히면 사용): ⏱ 이번 턴 +10초(한 턴 1번) / 💡 남은 합 개수 확인(한 게임 3번, 0개면 '결')
- 시작할 때 학년·학기 선택 → 문제는 `알짜 정리 학습지(정답)`의 빈칸 단어가 정답 (5학년 2학기 · 6학년 1·2학기, 약 850문항 / 정답은 공백 포함 9자까지)
- 컴퓨터: 내가 행동한 뒤 **10초 안에 반드시 답합니다**(패스 없음). 난이도는 실수 확률로 나뉩니다 — 쉬움 25% · 보통 12% · 어려움 4% (실수는 틀린 합을 부르거나, 합이 남았는데 '결'을 외치는 것). `netlify/functions/lib/games/gyeolhap/bot.js` 의 `PARAMS` 에서 조정합니다.
- '합!'을 누르고 카드를 고르면 고른 카드가 분홍색 테두리와 `✔ 순서` 표시로 크게 구분되고, 고르지 않은 카드는 흐려집니다. 위쪽 3칸에도 고른 번호가 나타납니다.
- 규칙 숫자(30초·5초·+10초·힌트 횟수 등)는 `gyeolhap/index.js` 맨 위 상수에서 바꿉니다.
- 문제 추가: `gyeolhap/bank-social.js` 에 (화면의 학기 선택지는 `public/js/games/gyeolhap.js` 맨 위 `SEMESTERS` 도 함께 고치세요)  `[학년, 학기, 단원, 단원이름, 소제목, 문장((      )이 빈칸), 정답]` 한 줄을 넣으면 학년·학기 선택에 반영됩니다.
- 힌트 = 문제 풀이: **분수의 나눗셈 · 소수의 나눗셈 · 비례배분** (방 만들 때 종류 선택, 기본은 모두 섞어서)
- 컴퓨터 연습: 항상 최선을 고르지 않고 **만들 수 있는 족보 중 확률로 결과가 나옴**. 난이도 쉬움/보통/어려움 (어려울수록 높은 족보 확률 ↑)
  - 확률 조정: `netlify/functions/lib/games/memory-poker/bot.js` 의 `WEIGHTS`
- 태블릿(가로/세로): 왼쪽 카드판 + 오른쪽 족보표·타이머·선택칸·버튼이 한 화면에 보이도록 배치 (폰은 위→아래 한 줄)

## 배포 순서
1. **GitHub**: 이 폴더 전체를 새 저장소에 올립니다.
2. **Neon**: 프로젝트를 만들고 *Connection string*을 복사합니다. 호스트에 `-pooler`가 붙은 주소를 쓰세요. (테이블은 첫 요청 때 자동 생성됩니다)
3. **Netlify**: *Add new site → Import from GitHub* 로 저장소를 연결합니다. (설정은 `netlify.toml`에 들어 있어 그대로 두면 됩니다)
4. **환경변수**: Netlify → Site configuration → Environment variables 에 `DATABASE_URL` = Neon 주소를 추가하고 다시 배포합니다.
   (Netlify의 Neon 연동 기능을 쓰면 `NETLIFY_DATABASE_URL`이 자동으로 들어가며, 이 경우도 그대로 동작합니다.)
5. 태블릿 2대로 접속해 확인: 한쪽이 **방 만들기** → 4자리 번호 → 다른 쪽이 **번호로 입장**.

## 로그인 · 교사 메뉴
- **교사 등록(처음 한 번)**: 학생 화면 아래 "교사 로그인" → "처음이에요 → 교사 등록"에서 **교사 아이디 · 비밀번호(6자 이상) · 학급 코드**를 직접 정합니다. 선생님마다 자기 아이디·학급 코드를 쓰고, 이미 쓰는 아이디나 학급 코드는 등록되지 않습니다. 선생님마다 학급이 분리되어 서로의 학생·기록을 볼 수 없습니다. 비밀번호는 암호화(scrypt)해서 저장하고 8시간 로그인이 유지됩니다.
  - **배포 직후 먼저 등록하세요.** 먼저 등록한 사람이 그 아이디·학급 코드를 가집니다. (이미 `6200` 학급에 등록한 학생들이 있다면, 아이디 `0227kkm` · 학급 코드 `6200`으로 등록하면 그대로 이어집니다.)
  - 비밀번호를 잊으면 화면에서 찾을 수 없습니다(Neon의 `teachers` 테이블 관리자가 직접 지워야 다시 등록 가능). 같은 와이파이에서 10분에 10번 넘게 틀리거나 등록을 시도하면 잠시 막힙니다.
- **학생**: 학급 코드 + 교사가 정해 준 비밀번호(영문·숫자 4자, 대소문자 구분 없음)로 로그인합니다. 비밀번호만으로 누구인지 정해지므로 **한 학급 안에서는 학생마다 달라야** 하고, 등록할 때 겹치면 자동으로 막힙니다(다른 학급과는 겹쳐도 됩니다). 이름은 등록된 명단에서 가져옵니다. 12시간 유지, 같은 와이파이에서 10분에 60번 넘게 틀리면 잠시 막힙니다.
- **교사 메뉴**
  - 학생 명단·등록: `엑셀 양식 받기` → 번호·이름·비밀번호를 채워 `엑셀/CSV 올리기`(또는 엑셀에서 복사해 붙여넣기) → 미리보기 → 등록. 같은 번호를 올리면 이름·비밀번호가 수정됩니다. 문제가 하나라도 있으면 아무도 등록되지 않고 이유가 표시됩니다. (엑셀이 `0123`을 `123`으로 바꿔도 4자리로 맞춰 읽습니다.)
  - 학생별 활동: 문제 풀이 기록(오답만 보기), 게임 결과(상대·승패·점수)
  - 오답 분석: 우리 학급에서 많이 틀린 문제 순위
  - `활동 기록 엑셀`: 학생별 요약 + 전체 문제 풀이 기록을 한 파일로 내려받기
- 엑셀 읽기·쓰기는 교사 메뉴를 쓸 때 SheetJS(cdnjs)를 불러옵니다. 학교 망에서 막히면 붙여넣기와 CSV가 대신 동작합니다.
- 학생 비밀번호는 교사가 명단에서 볼 수 있도록 그대로 저장됩니다(4자 간이 비밀번호 용도).

```
  js/core.js                 공통: 게임 목록, 방 만들기/입장, 서버 동기화, 타이머
  js/games/memory-poker.js   기억 포커 화면
  js/games/gyeolhap.js       결합 화면

netlify/functions/
  api.js                     API 입구 (모든 요청이 여기로)
  lib/rooms.js               방 생성/입장/상태 저장 (모든 게임 공통)
  lib/games/index.js         게임 등록부
  lib/games/memory-poker/    규칙(rules) · 문제 생성(questions) · 컴퓨터(bot) · 진행(index)
  lib/games/gyeolhap/        규칙(rules) · 사회 문제 은행(bank-social, questions) · 컴퓨터(bot) · 진행(index)
  lib/games/twelve-janggi/   말·판 규칙(rules) · 컴퓨터(ai) · 수학 문제(questions) · 진행(index)
test/                        자동 테스트 (npm install 후 npm test)
```

## 서버 안정성 설계
- **방마다 독립된 한 줄**(rooms 테이블)이라 방이 많아도 서로 영향이 없습니다.
- **낙관적 잠금**: 두 학생이 동시에 눌러도 서로의 변경을 덮어쓰지 않고 자동 재시도합니다.
- **짧은 응답**: 바뀐 게 없으면 아주 작은 응답만 보냅니다. 폴링 간격은 1.5~2.5초이며 학생마다 조금씩 어긋나게 해 한꺼번에 몰리지 않습니다. 탭이 숨겨지면 8초, 오류가 나면 점점 느려집니다.
- **Neon HTTP 드라이버**: 요청마다 연결을 유지하지 않아 연결 수 제한에 걸리지 않습니다.
- **서버 기준 시각**: 타이머는 서버가 기준이라 태블릿 시계가 달라도 공정합니다.
- **숨겨진 정보**: 암기 단계 이후에는 16장의 정체와 상대의 선택을 학생 기기로 보내지 않습니다.
- 3시간 지난 방은 자동 정리됩니다. 방 번호는 4자리(0000~9999)라 동시에 열 수 있는 방은 최대 1만 개입니다.

## 새 게임 추가하기
1. `netlify/functions/lib/games/<새게임>/index.js` — 규칙 모듈 (`create / join / advance / handle / view / stableForPoll`, 기억 포커 참고)
2. `netlify/functions/lib/games/index.js` 에 한 줄 등록
3. `public/js/games/<새게임>.js` — `App.registerGame({...})` 로 화면 등록, `index.html`에 script 한 줄 추가
